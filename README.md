# Calculator

#### 介绍
这是一款能精确算出数据的计算器，目前在试验阶段，只有命令行版本，GUI版本正在加紧研发。
#### 警告：
请勿输入过大数值，可能导致电脑卡死！

#### 软件架构
Windows：x86系列硬件
Linux/MacOS：支持所有

#### 安装教程

Windows：
    下载main.exe，无需安装
Linux/Macos：
    需要python环境
    下载main.zip或main.tar.gz，解压后到达main.py所在目录
    执行python -m main.py
